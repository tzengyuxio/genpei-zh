# 片頭平家物語的書法字

Opendat.gp 第 14～17 張（祇園精舍之鐘聲／有諸行無常之響／沙羅雙樹之花色／顯盛者必衰之理），每個字一個檔：`<張號>-<第幾字>-<字>_<書家>_<法帖>.png`（工具只看開頭的 `<張號>-<第幾字>-`）。

- 格式：白底黑字，裁到字形邊緣，尺寸不拘（例如全字庫 <https://www.cns11643.gov.tw/> 書法字的 PNG 可以直接用）。
- 同一個字在不同位置各有一檔，可以用不同字形（例如四個「之」）。
- 大小與位置記在 `layout.json`，用 `python3 tools/calligraphy_editor.py --bg <片頭擷取畫面>` 產生的網頁調整。
